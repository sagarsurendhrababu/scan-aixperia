# SSO Server

## Start

```bash
npm install
npm start
```

Open `http://localhost:3000/?designId=xxx&modelId=yyy`

## Configuration

Edit `config.js`, change these 4 values:

```js
APPUID: 'Your Coohom account UID',
APPKEY: 'Your app key',
APPSECRET: 'Your app secret',
LANUCH_ID: 'Your workbench mini-app launch ID',
